# Security Policy

## Responsible use

Use this project only in authorized lab environments. Obtain informed local consent before capturing or transmitting screenshots. Keep diagnostic operations restricted and never automatically execute downloaded files.

## Reporting vulnerabilities

Report security concerns privately to the maintainer using GitHub private vulnerability reporting if enabled, or request a private contact method without posting vulnerability details publicly.

Do not include credentials, private screenshots, or personal information in public issues. If a Discord token or webhook is exposed, revoke or rotate it immediately.

## Release verification

Review source code and release archives before running them. Test in an isolated Windows VM with non-sensitive data. Verify authorization checks, local consent, and logging before use.
